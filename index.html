这台设备上没有一个几百 MB 的模型是在你没点头的情况下落地的。这种事换作别家会开弹窗、发公告、请你点「稍后」—— Google 的选择是干脆不提。你现在看到的这一屏，就是它没做到的那部分。

正在看你硬盘上有什么…

想被塞满的话，三步

  1. 地址栏打开 chrome://flags
  2. 把 #optimization-guide-on-device-model 和 #prompt-api-for-gemini-nano 都设为 Enabled
  3. 重启 Chrome；模型随后自动下载，这一页会自己让开

门槛（Google 文档写的，不是我编的）：桌面版 Chrome 138+；存放 Chrome 个人资料的那个卷至少 22 GB 可用空间；下载完之后可用空间跌破 10 GB，它会把模型删掉，等空间够了再自己重下。企业策略 BuiltInAIDisallowed 能把整台机器的这条路直接焊死。查模型实际多大、下到哪儿了：chrome://on-device-internals。

顺便一条实打实的数据：调用这个 API 时 Chrome 自己在控制台列出的「受支持输出语言」是 de / en / es / fr / ja —— 没有中文。它照样能用中文给你写两千字（本项目实测如此），只是中文从来不在它保证质量的那份名单上。

出处：developer.chrome.com/docs/ai/prompt-api

为什么手机上看不到它

不是你配置错了，也不是机型不够好。Google 自己的文档原话：

非 Chromebook Plus 设备上的 Android 版 Chrome、iOS 版 Chrome 和 ChromeOS 版 Chrome 尚不支持使用基础模型的 API。

所以你在安卓的 chrome://flags 里翻不到 #prompt-api-for-gemini-nano —— 这条路目前在手机上根本不存在，别为它去刷机、换浏览器或者装「AI 加速包」。
另外提醒一句：LanguageModel 只在 https / localhost / file 这类安全上下文里暴露。如果此刻是用 http://192.168.x.x 从电脑上连过来看的，那属于「上下文不安全」，不是「你这台设备不行」。

出处：developer.chrome.com/docs/ai/prompt-api
